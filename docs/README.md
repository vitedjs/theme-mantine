# Vited Mantine Theme

The default Mantine theme for Vited documentation sites, built with React 19
and Mantine.

Features:

- Responsive Mantine AppShell layout with header, sidebar navigation and a table
  of contents
- Light and dark color modes, following the system by default and remembering
  the user's choice
- Localized interface in English and Simplified Chinese
- Locale-aware fuzzy search in a Mantine Spotlight, opened with `Ctrl+K` / `⌘K`
- GitHub and Donate links from project metadata
- Heading anchor links and a page outline that stays in view while scrolling
- Markdown and MDX code blocks highlighted with Shiki and Mantine CodeHighlight,
  with copy controls

Get started with the [installation guide](./installation.md) and see the
[configuration reference](./configuration.md) for all options.
