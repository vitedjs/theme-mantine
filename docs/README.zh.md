# Vited Mantine 主题

默认的 Mantine 版 Vited 文档主题，使用 React 19 和 Mantine 构建。

功能特性：

- 基于 Mantine AppShell 的响应式布局，包含页头、侧边导航和目录
- 明暗色彩模式，默认跟随系统并记住用户选择
- 英文和简体中文界面翻译
- 基于 Mantine Spotlight 的本地化模糊搜索，使用 `Ctrl+K` / `⌘K` 打开
- 从项目元数据生成 GitHub 和赞助链接
- 标题锚点链接，以及滚动时保持可见的页面目录
- 使用 Shiki 和 Mantine CodeHighlight 高亮 Markdown 和 MDX 代码块，带复制按钮

从[安装指南](./installation.md)开始，并在[配置参考](./configuration.md)中查看所有选项。
